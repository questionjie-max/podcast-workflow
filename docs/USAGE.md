# 使用手册 · 播客工坊

> 面向「想给孩子做睡前故事」和「想做个人播客」的普通人。5 分钟上手。

## 一、安装与启动

```bash
bash install.sh     # 一键安装(建环境、装依赖、检查 ffmpeg、建桌面快捷方式)
podcast-studio serve   # 启动(安装后已入 PATH;或 .venv/bin/podcast-studio serve)
```

浏览器打开 **http://localhost:8686**。第一次会进入引导:选节目类型 → 选写作引擎 → (可选)了解声音克隆。

> 没有任何 API Key 也能用:**演示模式**用内置示例文稿 + 免费 edge-tts 真实语音合成,整条流程都能体验。

## 二、给孩子做睡前故事(推荐路径)

1. **新建节目** → 切到「📄 我有素材」,把你查到的知识粘进去(比如孩子今天问"为什么会下雨",加上你查到的答案);懒得打字就点「🎙️ 说一句」,说完自动变文字(需在设置里配豆包 ASR)
2. 节目类型选 **🌙 睡前故事**,时长 2/3/5/8/10/15 分钟任选(首期时长可能偏差较大,产品会越用越准)
3. 声音先选 🆓 里的中文音色(如晓晓)体验;以后在设置里克隆你自己的声音
4. 点「开始制作」→ 从候选选题里挑一个(素材模式会直接写稿)→ **审稿页可以改每个字**
5. 点「满意了,开始合成」→ 等 1-2 分钟 → 试听、下载 MP3

**每晚自动更新**:设置 → ⏰ 每晚定时生成 → 填话题池(一行一个,如"为什么会下雨?""月亮为什么变弯?""彩虹怎么来的?")→ 保存。电脑开机且服务在跑的话,每晚 20:30 自动出新一期,话题轮换。

## 三、做成人播客

- 节目类型选 🎙️ 播客,「🔍 给个选题」输入主题范围(如"上海房产"),从候选里挑
- 想让选题更贴实时热点:设置 → 🔍 搜索配置,接 Tavily(国际)或博查(国内)。
  搜索结果会自动过一道**内容安全过滤**(黑名单域名+敏感词,睡前故事强制开启),
  并做**事实核查轮**:选题逐条判定可靠/存疑/无从核实,存疑的挂 ⚠️ 标记、
  无从核实的直接丢弃;搜索总轮次默认 2、可配到 3(设置里改)。选题卡片能看到来源
- 完成后:shownotes 一键复制去小宇宙/喜马拉雅;MP3 带封面和标准响度,直接上传
- 想订阅到播客客户端:我的电台底部的 RSS 地址(公网订阅需配合内网穿透)

## 三·五、连接大模型(重要,30 秒搞定)

设置 → ⚡ 一键预设:选厂商(DeepSeek/Qwen/Kimi/MiMo/OpenAI)自动填充接口地址和模型,只需填入 API Key。
**更简单**:点「🔎 检测」,自动发现本机 **CC Switch / Magpie** 网关里已配置好的供应商(含 key),
选中即导入——装过网关的用户零打字。
两个都不顺?点「🩹 一键修复连接」:自动把本机所有可用连接(网关/预设/已存)逐个真实测试,
能通的直接配上,每个失败原因都写得明明白白。

## 四、用你自己的声音

1. 设置 → 🗣️ 我的声音:填名字(如"爸爸的声音"),用浏览器直接录音(给一段覆盖各类发音的录音稿),或上传 30-60 秒现成录音
2. 选音色前可点「🔊 试听」先听(免费 edge 音色即时合成;带 🔑 的音色需配好 Key)
3. 之后新建节目时,声音下拉的「🗣️ 我的声音」里选它
3. 克隆合成走 MiMo TTS,需要配置其 API Key

> 请只克隆本人或已获授权的声音。

## 五、审稿与细修

- 审稿页:文稿可直接改;合规报告逐维度展示;改完点「保存修改」再合成
- 完成页:某一段读得不满意?在「🎚️ 分段细修」点那一段的「↻ 重录」,其余不动;
  「📦 打包下载」一次拿走音频+文稿+shownotes+封面
- 文稿质量取决于写作引擎:设置里切换 DeepSeek/Qwen/Kimi/MiMo 等任意 OpenAI 兼容接口,「🔌 测试连接」验证

## 五·五、写作增强

- **时长校准**:选了 5 分钟但只出了 3 分钟？产品会从每期真实节目学习「字符/秒」速率,越用越准(首期偏差较大属正常;示例节目不参与学习)
- **垫乐**(可选):设置 → 🎵 垫乐,填一个本地音乐文件路径(mp3/m4a/flac,版权自担),合成时自动循环铺底+首尾淡入淡出,默认音量很低不抢人声
- **命令行自检**:`podcast-studio doctor` 逐项体检环境/配置/凭据/豆包授权,出「下一步」指引
- **字幕与章节**:成品自带 ID3 章节(播放器可跳转);`GET /api/episodes/{id}/subtitles` 或打包下载可得 SRT 字幕(剪映可用)
- **示例电台**:我的电台底部的「🎯 示例」分区是随包示例(只读,不进 RSS、不参与校准),可以秒听效果;听了喜欢就去做自己的第一期
- **真实联调自检**:`podcast-studio doctor --probe` 对已配置的 LLM/TTS/搜索发最小真实请求,
  把“已配置”变成“已验证”;ElevenLabs 等 Key 填错会当场 401
- **诊断包**:`podcast-studio doctor --bundle` 生成脱敏 zip(报告+掩码配置+日志),
  出问题时可交给开发者;不含 Key/音频/文稿明文
- **一键冒烟**:开发/排障时跑 `bash scripts/smoke.sh`,13 项检查快速判定服务健康
- **情绪弧线**:写稿前自动分析内容,规划节拍和情绪,文稿贴合内容本身的情感变化
- **结构模板**:新建节目页可选结构(渐弱入眠式/三幕式/NPR 钩子式等 12 个),写稿按节拍铺陈

## 五·六、备份与恢复(强烈建议)

```bash
podcast-studio backup                     # 备份节目/声音/校准到 ~/.podcast-studio/backups
podcast-studio backup --include-config    # 连 API Key 一起备份(内含明文，请只放可信位置)
podcast-studio restore ~/.podcast-studio/backups/podcast-studio-backup-YYYYmmdd-HHMMSS.zip
```

- **每日自动快照**:有节目且距上次 24 小时时，启动会顺手备份一份，保留最近 7 份
- **恢复前会自动快照当前数据**，误操作可回滚；默认只恢复节目/声音/校准，不动 config
- 排除 `previews` 缓存，备份体积小；恢复时拒绝路径穿越
- 换电脑：把备份 zip 拷过去 → `restore` 即可；也可以直接拷贝整个 `~/.podcast-studio/`

## 五·七、用量与归档

- **每期用量**:完成页会显示「📊 本期用量:写稿 N 次 · 输入 X 字 / 输出 Y 字 · 语音 Z 字」。
  设置 → 📊 用量与费用估算 里填单价后,还会显示估算金额(以厂商控制台为准)
- **归档**:不想让某期一直占着列表?电台里点 🗃️ 归档——只是收起,不删除文件,
  随时在「🗃️ 已归档」里取消归档。执行中的节目不能归档(给 409 提示)
- **清缓存**:`podcast-studio clean` 预览可清理的试听缓存/合成残留/旧备份,
  加 `--yes` 才真正删除;节目、声音、成品分段与配置永不会被清理

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 合成失败:ffmpeg | 安装 ffmpeg(`apt/brew install ffmpeg`)后重试(失败会从失败分段续跑) |
| LLM 报认证失败 | 设置 → 测试连接,确认 Key/base_url(带 `/v1`)/模型名 |
| MiMo 证书错误 | 先更新系统证书或 certifi;关闭校验仅作最后手段 |
| 声音下拉 🔑 组合成报错 | 该组需要对应 Key(设置 → TTS 接口配置) |
| 网关探测不到 / 连接全失败 | 确认 Magpie/CC Switch 正在运行、供应商配了模型名;或直接点「🩹 一键修复连接」看每个候选的失败原因 |
| 换电脑迁移 | `podcast-studio backup` 后把 zip 拷到新机器 `restore`；或直接拷贝 `~/.podcast-studio/` |
| 上传提示“太大/不像音频/太短” | ASR/克隆上传上限 20MB；克隆采样 5–120 秒；支持 wav/mp3/m4a/webm/ogg/flac |
| 局域网/远程访问 | 默认只绑本机；开放需 `server.allow_lan=true`。产品无账号体系，等于把 API 交给同网段所有人，请谨慎 |
| 端口 8686 被占 | 默认自动换下一个可用端口；若已有本产品在跑会直接提示，不重复启动 |
| 测试全红/真实 API 全失败 | 检查 `ALL_PROXY` 是否为 `socks://`（httpx 不支持）；启动会自动忽略并提示，建议改 `socks5://` 或设 `HTTPS_PROXY` |
| 想看日志 | `<数据目录>/logs/app.log`（2MB × 3 轮转，密钥已脱敏） |
| Docker 部署 | `UID=$(id -u) GID=$(id -g) docker compose up -d`；数据在 `./podcast-data`；默认只绑 127.0.0.1 |

## 七、命令行(可选)

```bash
podcast-studio make "为什么会下雨" --style bedtime --minutes 5     # 交互选题
podcast-studio make story.txt --material --style bedtime --yes     # 素材全自动
podcast-studio doctor                    # 环境/配置/凭据体检
podcast-studio doctor --probe            # 最小真实请求验证 provider
podcast-studio doctor --bundle           # 脱敏诊断包
podcast-studio clean                     # 预览可清理缓存（--yes 才删）
podcast-studio backup                    # 备份
podcast-studio restore <备份.zip>        # 恢复
```
