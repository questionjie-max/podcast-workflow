🛡️ 关于与信任

装在你自己电脑上的播客与睡前故事工作室——用你的声音讲，每一集都由家长审定，数据不出门。

你的数据

所有数据都存在本机 ~/.podcast-studio：config.json 权限 0600，数据目录 0700，并自动备份 config.json.bak。除了你调用的 AI 服务（写稿/语音），内容不经过任何第三方。

儿童内容安全

儿童模式强制黑名单 + 敏感词过滤、事实核查（≤3 轮），搜不到可靠来源就丢弃选题——宁可少一集，不可错一集。

免费与付费

本软件永久免费开源（自托管）；你只需要为自己的 AI 服务 API 用量付费；免费路径（edge-tts + 演示模式）零成本可用。
